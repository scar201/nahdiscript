            ABOUT

            
The Story Behind NahdiScript


            


                NahdiScript is a modern programming language built to make
                programming simpler, cleaner, and easier to understand.

                It focuses on readability, performance, and developer
                experience while providing a solid foundation for future
                features like null safety, strict typing, and a powerful
                standard library.
